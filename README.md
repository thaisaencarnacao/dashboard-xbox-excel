# 🎮 Xbox Sales Dashboard (Excel)

Este projeto apresenta uma análise de vendas de assinaturas Xbox por meio de um dashboard desenvolvido no Microsoft Excel.

O objetivo é transformar dados brutos em informações visuais claras e úteis, permitindo uma análise eficiente do desempenho de vendas e apoiando a tomada de decisões baseada em dados.

---

## 📊 Objetivo do Projeto

Construir um dashboard de vendas que permita analisar:

- Receita total de vendas
- Ticket médio por cliente
- Tipos de assinatura (Monthly, Quarterly, Annual)
- Plano Ultimate (sim/não)
- Impacto de add-ons (EA Play e Minecraft Season Pass)
- Uso de cupons e seu impacto na receita
- Distribuição geral de clientes e assinaturas

## 📈 Principais Análises Realizadas

- Receita total de vendas

- Análise do impacto de add-ons na receita
- Avaliação do uso de cupons e descontos
- Indicadores de performance (KPIs)

## 💡 Principais Insights

- Assinaturas anuais tendem a gerar maior receita por cliente
- Add-ons como EA Play e Minecraft aumentam o ticket médio
- Cupons impactam diretamente o valor final das vendas
- A segmentação de clientes permite identificar padrões de consumo

---

## 🚀 Conclusão

Este projeto demonstra habilidades em organização de dados, construção de dashboards e análise de indicadores de desempenho, aplicados a um cenário de vendas no setor de assinaturas digitais.

O Excel foi utilizado como ferramenta principal para transformação de dados em insights visuais e estratégicos.
